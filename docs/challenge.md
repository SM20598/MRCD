# MRCD-Challenge
As part of this work, we present MRCD-challenge, a novel outdoor SLAM competition built around the MRCD data set. MRCD-challenge build on the [Codabench](https://www.codabench.org/) Framework, offering a competitive opportunity for SLAM enthusiasts and researchers to compete in SLAM algorithm development for robust outdoor robotics. With MRCD-challenge we hope to provide a novel, easy-to-access benchmark that crystalizes the strongest performing SLAM algorithms and serves as a motivation for developers to continously improve their algorithms.
